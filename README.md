# RPG SAGA

Игра, где герои сражаются друг с другом.

## Запуск

npm install
npm run start

## Тесты

npm test

## Герои и способности

- Рыцарь — Удар возмездия (+30% урона)
- Лучник — Огненные стрелы (1 раз за бой) и Ледяные стрелы (2 раза за бой)
- Маг — Заворожение (противник пропускает ход)
